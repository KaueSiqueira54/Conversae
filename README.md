## 📖 Sobre o Projeto

O **Conversaê** é uma plataforma web voltada para tornar o cuidado com a saúde mental mais **acessível, simples e humano**. A plataforma conecta usuários a psicólogos qualificados, oferecendo a **primeira consulta gratuita** e um ambiente acolhedor e seguro para dar o primeiro passo no cuidado com a saúde mental.

> *"Você não precisa enfrentar tudo sozinho."*

O projeto nasceu a partir de um contexto preocupante: segundo dados da OMS, o Brasil lidera o ranking mundial de ansiedade, afetando cerca de 18 milhões de pessoas (9,3% da população). O Conversaê surge como resposta a barreiras como o alto custo das consultas privadas, a longa espera na rede pública e a sobrecarga dos profissionais de saúde.

---

## ✨ Funcionalidades

- **Sessão inicial gratuita** — agendamento sem custo para o primeiro contato com um profissional
- **Busca por especialidade** — filtros para encontrar o psicólogo ideal conforme os temas que o usuário deseja trabalhar (ansiedade, autoestima, etc.)
- **Agendamento online** — calendário integrado para escolher horários disponíveis do profissional
- **Área do psicólogo** — interface dedicada para profissionais cadastrados na plataforma
- **Cadastro e login de usuários**
- **Design responsivo** — layout adaptado para mobile, tablet e desktop
- **Acessibilidade com VLibras** — suporte à Língua Brasileira de Sinais (Libras) via plugin governamental

---

## 🚀 Como funciona

1. **Selecione o que está sentindo** — utilize os filtros para escolher os temas que deseja tratar
2. **Escolha o psicólogo por especialidade** — encontre o profissional mais adequado ao seu momento
3. **Agende sua sessão inicial** — escolha um horário disponível; a primeira sessão é gratuita

## 🛠️ Tecnologias Utilizadas

O projeto é uma aplicação web estática desenvolvida com tecnologias front-end puras:

## ⚠️ Aviso Importante

> Este **não** é um serviço de emergência. O Conversaê atende apenas de forma agendada.
>
> Se você está em crise ou em risco de vida, entre em contato com o **CVV (Centro de Valorização da Vida)** pelo número **188** ou acesse [www.cvv.org.br](https://www.cvv.org.br). O atendimento é gratuito, sigiloso e disponível **24 horas**.
